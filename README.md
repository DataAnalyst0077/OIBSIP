## Task 1: Retail Sales Analysis (EDA)

### Project Overview
Exploratory Data Analysis (EDA) on retail sales data to analyze customer demographics, sales trends, and product performance.

### Dataset Details
* **Total Records:** 1,000 entries (Zero missing values)
* **Key Columns:** Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

### Key Insights & Workflow
* **Data Cleaning:** Verified data types and ensured 100% data completeness.
* **Descriptive Statistics:** Calculated mean, median, mode, and standard deviation across numerical columns.
* **Time Series Analysis:** Analyzed sales trends (`Total Amount`) over time.
* **Demographic & Category Analysis:** Evaluated purchasing patterns by age, gender, and product category.

### Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
